# Workbench API

The Node route loads the workspace and serves damaged-file recovery. Every POST checks the browser origin and decodes its command before calling the local workspace or OpenFGA. Errors return a category and generated correlation ID. Tuple publish diagnostics can add application reason codes, source coordinates, and allowed schema choices. The browser looks up tuple identities against its captured draft.

Access Review commands read selector metadata, walk published containment links, and evaluate captured resource and relation pairs. The evidence command's optional Access Review mode rechecks the original decision before returning supporting edges. See the [contract](../../../lib/workbench-access-review-contract.ts).
